Reading connection fields

The source identifies the reported client endpoint. The destination identifies the system being reached. Remote authentication to a laboratory destination is not the same record as a direct workstation session.

Use connection type and field definitions when requesting support. Address information alone does not establish an individual's exact location or identity.
