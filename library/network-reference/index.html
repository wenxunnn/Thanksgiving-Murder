This support reference identifies address conventions used by university laboratories and affiliated institutional services.

Source and destination

The source is the client endpoint reported for a connection. The destination is the system or service being reached. A laboratory server can be the destination of a remote session without the client being an on-campus workstation.

The VPN gateway may log an external public source before tunneling and separately assign an internal tunnel address. Check the field names and connection type before comparing addresses. A successful login confirms accepted credentials; it does not independently establish physical presence or the identity of the person using those credentials.

Affiliated institutional services

The digital library, St. Agnes university-affiliated medical services, and the affiliated housing archive use separate private server segments behind the shared institutional gateway. A server's private address is not the same as a visitor's public source address.

For routine setup instructions, consult the Remote Access Guide (2008).
