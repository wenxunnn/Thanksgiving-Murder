Laboratory network
address conventions

Read the source address together with the recorded connection type when interpreting an instrument-server access record.

ConnectionTypical source formatReference
Laboratory terminal10.42.x.xInternal laboratory network
University gateway128.46.x.xCampus gateway or translated outbound address
Remote VPNExternal endpoint retainedRemote-access service

Interpreting an access record

A login identifies the account used and the service reached. It does not independently establish the physical position of the account holder.

For Remote VPN entries, the source field may preserve the external endpoint rather than a laboratory terminal address. Compare both fields before attributing a session to a campus workstation.
